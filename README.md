A machine learning classification project that predicts passenger survival on the Titanic dataset.

Project workflow:
- Data Exploration (EDA)
- Data Cleaning
- Missing Value Handling
- Feature Selection
- Encoding
- Train/Test Split
- Random Forest Classification
- Model Evaluation
- Model Saving with Joblib

Results:
- Accuracy: 82.68%
- Precision (Survived): 86%
- Recall (Survived): 69%
- F1 Score: 77%

Technologies:
Python, Pandas, NumPy, Scikit-learn, Joblib
